Architecture & Engineering Specifications

About ResumeIQ

A production-grade, dual-mode resume optimization engine designed for deterministic parsing and ATS compatibility scoring.

Core Architecture

ResumeIQ is built on a decoupled, service-oriented architecture. The core ATS parsing engine is shared identically between local execution mode and AWS cloud deployment mode to prevent logic divergence or fake implementations.

Local Mode

  • Backend: Python / Flask REST API
  • Database: Local SQLite (`data/resumeiq.db`)
  • Storage: Local filesystem (`storage/uploads` & `storage/generated`)
  • Dependencies: Zero AWS account or external cloud services required

AWS Cloud Mode

  • Compute: AWS Lambda serverless execution
  • API Gateway: Amazon API Gateway REST endpoints
  • Database: Amazon DynamoDB table
  • Storage: Amazon S3 private storage bucket

Deterministic Scoring Methodology

Unlike tools relying on randomized numbers or unexplainable opaque AI outputs, ResumeIQ scores are 100% deterministic and transparent.

General Quality Score (100 Max)

  • Structure & Headers (25): Evaluates presence of standard sections.
  • Contact Data (10): Email, phone, and professional links.
  • Technical Skills (20): Skill catalog breadth & categorization.
  • Work Experience (15): Experience depth & action orientation.
  • Projects (15): Project presence & technical details.
  • Formatting Hygiene (10): Readable text density & length.
  • Certifications (5): Verified credentials & awards.

Job Match Score (100 Max)

  • Keyword Match (30): Domain keyword alignment ratio.
  • Skills Match (25): Required technical skills match ratio.
  • Experience Relevance (15): Role alignment.
  • Projects Relevance (10): Applied skill demonstration.
  • Resume Structure (10): ATS section hierarchy.
  • Contact Info (5): Reachability score.
  • Formatting (5): Document readability.

Privacy Policy & Security

Uploaded resumes contain sensitive personal contact information. In local mode, documents and database records remain exclusively on your local machine. In cloud mode, files are stored in private, non-public S3 buckets protected by IAM least-privilege policies. You retain complete control to view and permanently delete any stored analysis and associated document at any time via the Dashboard.
